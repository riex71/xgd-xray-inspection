# 남은 한계 — XGD-1.2 추가분

1. 완결성 확인은 여러 예측이 **함께 놓친** 이물을 잡지 못한다. 합성 시험에서 줄어든 위험은 실제 현장 놓침 빈도의 증거가 아니다.
2. 불일치 확인은 모델 호출을 늘린다(장당 3호기 8.0회, 1·2호기 8.0회). 처리 시간은 측정했지만 다른 GPU·현장 장비에서는 검증하지 않았다.
3. 그룹(NCC ≥ 0.998)을 지키려고 3호기 13장을 다른 절반으로 옮겨 일부 촬영일이 보정·평가 양쪽에 걸친다. 약한 proxy(NCC ≥ 0.98)는 한 덩어리라 분리 단위로 쓰지 못했다.
4. 정책 선택은 반대 장비군 자료로 했지만, 선택이 충돌하면 두 장비군 결과를 함께 써서 조정했다. 전체 분석은 같은 개발 자료를 반복해서 본 내부 검증이다.
5. 장비별로 일정한 중심 치우침(3호기 −0.35px, 1·2호기 dx +0.9px)이 있다. 원천 장비 보정으로는 설명되지 않고, 라벨 중심 관례인지 모델 편향인지 구분하지 못했다.
6. 흔적 증강 강도 비교는 합성 이물(M2/M2v2)에 크게 의존한다. M2v2는 ROI 정합만 고친 것이며 대비·PSF 사실성을 인증하지 않는다.
7. 해상도 등록부는 정확한 폭×높이만 승인한다. 316×332 1호기처럼 새 형식을 쓰려면 그 조건의 라벨 보정 자료가 필요하다.
8. 외부 정상·이물 X-ray 자료는 적합성·권리·중복을 확인할 수 있는 것이 없어 쓰지 않았다. 정상 제품 특이도와 '이물 없음' 자동 판정은 여전히 평가할 수 없다.
9. 2호기 9월형 촬영 조건(8/31·9/1, Q4가 낮은 잡음 특성)은 1·2호기용 검출기 학습에만 쓰여 보류 라벨이 없다. 그래서 1.2는 9월 평가 2호기 영상을 품질 FULL/REVIEW로 보내고, 평가 79장 자동 확정은 0장이다. 이 조건을 자동 확정하려면 학습에 쓰지 않은 같은 조건의 라벨 영상으로 보정해야 한다.

아래는 XGD-1.1 기준선의 한계(역사 기록)다.
# 남은 한계

직접 누수 방지(평가 정답 미사용, 학습·보류 영상 분리)와 별개로 아래 한계가 남는다.

1. 같은 공급처 개발 356장을 9/21 이후 반복해서 분석·선택에 썼다. 이 패키지의 결과는 내부 검증이며 독립 확증이 아니다.
2. 물리적 시험편 ID가 없다. 같은 날짜에 세 장비가 비슷한 수를 촬영했고 정답 배치가 비슷한 쌍이 있어, 장비 전이 평가에 같은 시험편이 섞였을 수 있다.
3. 정상 제품 영상이 0장이다. '이물 없음' 판정의 안전성과 제품 단위 특이도는 평가할 수 없다.
4. 1·3호기 개발 영상은 모두 이물 3개, 중심 x가 제품 폭의 25~38%에 몰려 있다. 위치·개수 다양성이 작다.
5. 3호기 보정 자료는 100장·촬영일 5개다. 반복 분할 수는 독립 표본 수가 아니며, 독립 보정(P-IND-strict)에서는 등급이 성립하지 않는 경우가 많다.
6. CRC α 0.05는 교환가능성 가정의 기대 전체 위험이다. LTT 확률 보장은 전제가 확인되지 않아 주장하지 않는다.
7. 정상 화질에서 신뢰도가 높은 오판(운영 seed 17에서 장비군별 2장)은 현재 규칙으로 거르지 못한다. 후보 신호: 사전 채택 기준을 충족한 후보 없음 — 3호기 판단 불가(주 설계에서 자동 확정된 실패 없음); 3 seed 전체 실패 중 신호가 표시한 수 C1 0/11, C2 1/11, C3 0/11 / 1·2호기 채택 기준 미충족(자동 확정된 실패 포착 0/3, 0/3, 0/3); 3 seed 전체 실패 중 신호가 표시한 수 C1 0/8, C2 0/8, C3 0/8. 실패 기하(E8): 3호기 실패 11장(3 seed) 중 11장은 예측이 정답 중심에서 3.04~4.02px 떨어진 위치 오차; 서로 다른 영상 8장 중 3장은 2개 이상 seed에서 반복; 1·2호기 실패 8장(3 seed) 중 5장은 예측이 정답 중심에서 3.06~3.72px 떨어진 위치 오차, 3장은 같은 영상(002_20200623_123055(5))의 반복 오탐(정답에서 약 24~25px); 서로 다른 영상 3장 중 3장은 2개 이상 seed에서 반복. 대부분 3px 기준을 조금 넘는 위치 오차이며, 라벨 중심 오차인지 모델 오차인지는 구분하지 못했다.
8. 촬영 조건 변화는 합성 열화로만 시험했다. 실제 장비의 잡음 스펙트럼·PSF·물리 배율 변화를 대표한다고 할 수 없다.
9. 위치·문맥·흔적 시험은 합성 영상이다. 합성 방법 2가지로 결론의 일관성을 봤지만 실제 새 이물·제품 분포를 대체하지 못한다.
10. 평가 79장은 정답 없이 판정 분포만 있다. 1호기 32장·3호기 2장이 자동 확정되지 않은 것이 정당한 차단인지 과차단인지 판단할 수 없다. 중단 조건은 정답 없이 분해했다(E7: 1호기는 9월 촬영 형식 변화에 따른 품질 gate 중단).
11. 다른 GPU·새 패키지 설치 환경에서는 검증하지 않았다(CPU 대 GPU 비교만 수행). 재학습 가중치는 제출 가중치와 비트 단위로 같지 않다.
12. 대조 학습의 YOLO seed 17은 9/28 학습분이라 실행 환경의 완전한 동일성을 소급 증명하지 않는다.
13. 장비별 보정(품질 기준·CRC λ)은 그 장비의 개발 영상 해상도에서 만들었지만, 다른 해상도로 들어온 같은 장비 영상을 직접 막는 규칙은 없다. 배율 범위는 profile 단위로만 본다. 평가 1호기(316×332)는 품질 gate가 멈췄지만 잡음 특성이 기준과 비슷했다면 352×332 영상으로 만든 1호기 보정값이 그대로 쓰였을 것이다. 평가 출력을 보고 찾은 문제라 이번 버전 규칙에는 넣지 않고 다음 버전 후보로 남긴다.
14. 판정 신뢰도는 검출한 이물의 평균 점수라서, 이물 하나를 놓쳐도 나머지 검출이 확실하면 자동 확정될 수 있다. 합성 시험(E9, 탐색): 3호기(진단 설계, 흔적 없는 M2 합성 이물): 자동 확정 179장 중 110장 실패, FN 위험 0.367 대 FP 위험 0.023; seed 불일치(C3)는 M2 조건의 실패 영상 0.514~0.766를 표시하지만 정상 영상도 0.363~0.479를 표시; 1·2호기(독립 보정, 흔적 없는 M2 합성 이물): 자동 확정 144장 중 69장 실패, FN 위험 0.103 대 FP 위험 0.004; seed 불일치(C3)는 M2 조건의 실패 영상 0.473~0.883를 표시하지만 정상 영상도 0.188~0.401를 표시. 정상 제품 자료가 없어 '놓침'을 직접 보정할 방법이 이번 자료에는 없다.
